# 企业级记忆引擎 - 环境配置与框架搭建指南
## 文档说明
本文档为记忆引擎项目的基础开发规范，所有开发人员必须严格遵循，保证项目架构一致性、可维护性和可扩展性。
---
## 一、基础环境要求
### 1.1 系统要求

## 二、项目架构与目录规范
### 2.1 整体架构分层
```
┌─────────────────┐  ┌─────────────────┐
│   CLI 客户端    │  │  飞书机器人端   │  接入层
└─────────────────┘  └─────────────────┘
          │                    │
          └─────────┬──────────┘
                    │
┌───────────────────────────────────┐
│            API 网关层             │  接口层
│  (FastAPI 统一路由、权限校验、限流)│
└───────────────────────────────────┘
                    │
┌───────────────────────────────────┐
│         记忆引擎核心层            │  业务逻辑层
│  [提取→存储→检索→更新→遗忘]       │
└───────────────────────────────────┘
          │                    │

│  关系型数据库   │  │  向量数据库     │  数据层
│  (SQLite/PG)    │  │  (Chroma)       │
└─────────────────┘  └─────────────────┘
```

### 2.3 目录访问规则
> 严格遵循单向依赖原则，禁止反向依赖：
> 1. 接入层（cli/feishu_bot/backend）只能依赖核心层（core）和数据层（db）
> 2. 核心层（core）只能依赖数据层（db），不能依赖任何接入层代码
> 3. 数据层（db）不能依赖任何其他层代码

## 三、从零开始搭建步骤
### 3.1 第一步：初始化项目
1. 克隆项目代码到本地：
```bash
git clone <仓库地址>
cd feishu-long-memory-agent
```
2. 创建并激活Python虚拟环境（必须使用虚拟环境，禁止全局安装依赖）：
```bash
# Windows PowerShell
python -m venv venv
.\venv\Scripts\activate

# macOS/Linux
python3 -m venv venv
source venv/bin/activate
```
3. 安装所有依赖：
```bash
pip install -r requirements.txt
```
### 3.2 第二步：配置环境变量
1. 复制环境变量模板：
```bash
cp .env.example .env
```
2. 填写.env文件中的必填配置项：
```env
# 基础配置
ENVIRONMENT=development
DEBUG=true
SERVER_PORT=8000

# 数据库配置
DATABASE_URL=sqlite:///./db/memory.db
VECTOR_DB_PATH=./db/vector_store

# LLM配置
OPENAI_API_KEY=your_openai_api_key
OPENAI_BASE_URL=https://api.openai.com/v1
EMBEDDING_MODEL=text-embedding-ada-002
LLM_MODEL=gpt-3.5-turbo

# 飞书机器人配置
FEISHU_APP_ID=your_feishu_app_id
FEISHU_APP_SECRET=your_feishu_app_secret
FEISHU_VERIFICATION_TOKEN=your_verification_token
FEISHU_ENCRYPT_KEY=your_encrypt_key

# 记忆引擎配置
DEFAULT_MEMORY_EXPIRE_DAYS=30
RETRIEVE_TOP_K=5
SIMILARITY_THRESHOLD=0.7
```
### 3.3 第三步：初始化数据库
1. 初始化关系型数据库表：
```bash
python -m db.relational.init_db
```
2. 初始化向量数据库集合：
```bash
python -m db.vector.init_vector_db
```
### 3.4 第四步：启动服务验证
1. 启动后端API服务：
```bash
uvicorn backend.main:app --reload --port 8000
```
2. 访问接口文档验证服务是否正常：
- 打开浏览器访问 http://localhost:8000/docs
- 能看到自动生成的Swagger接口文档即为成功
3. 测试CLI客户端是否正常：
```bash
python -m cli.main --help
```
能看到CLI帮助信息即为成功

## 四、开发规范
### 4.1 代码规范
- 所有Python代码必须遵循PEP8规范
- 使用black作为代码格式化工具，flake8作为代码检查工具
- 函数/变量名使用蛇形命名法，类名使用大驼峰命名法
- 所有对外API必须添加类型注解和参数校验
### 4.2 提交规范
Git提交信息必须遵循以下格式：
```
<type>(<scope>): <description>
```
type可选值：
- feat: 新功能
- fix: 修复bug
- docs: 文档更新
- style: 代码格式调整
- refactor: 代码重构
- test: 测试用例更新
- chore: 构建/工具链配置更新
### 4.3 调试规范
- 禁止在代码中留下print语句，使用logging模块打印日志
- 所有日志按级别分类：DEBUG/INFO/WARNING/ERROR
- 生产环境关闭DEBUG模式，禁止输出敏感信息（API密钥、用户隐私等）

## 五、框架可用性验证标准
搭建完成后，必须通过以下验证才能开始业务开发：
1. ✅ 后端服务正常启动，接口文档可访问
2. ✅ 关系型数据库初始化成功，表结构正确创建
3. ✅ 向量数据库初始化成功，可正常写入和查询向量
4. ✅ LLM接口调用正常，可正常生成embedding和文本回复
5. ✅ CLI客户端可正常运行，基本命令可执行
6. ✅ 飞书机器人回调接口可正常接收事件，可发送消息
---
## 六、后续开发指引
框架搭建完成后，按以下顺序开发核心功能：
1. 优先开发core层记忆存储、提取、检索核心逻辑
2. 开发backend层API接口
3. 对接CLI客户端功能
4. 对接飞书机器人功能
5. 编写测试用例和评测脚本
