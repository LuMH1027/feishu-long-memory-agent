## 3.1 实现命令搜索相关性加权算法
### 功能说明
CLI命令搜索结果优先级规则：
1. 完全前缀匹配 > 语义匹配
2. 高使用频率 > 低使用频率
3. 最近使用 > 很久之前使用

### 代码实现
```python
from datetime import datetime
from db.relational.models import Memory

def calculate_cli_relevance_score(query: str, memory: Memory) -> float:
    """计算CLI命令场景下的相关性得分"""
    base_score = memory.similarity_score if hasattr(memory, 'similarity_score') else 0.0
    
    # CLI命令特殊权重规则
    metadata = memory.metadata or {}
    
    # 1. 高频率使用的命令加分（最多加0.3分）
    count = metadata.get("count", 0)
    count_score = min(count * 0.05, 0.3)
    
    # 2. 最近使用的命令加分（30天内的命令最多加0.2分）
    recency_score = 0.0
    last_used = metadata.get("last_used_at")
    if last_used:
        try:
            last_used_time = datetime.fromisoformat(last_used)
            days_ago = (datetime.now() - last_used_time).days
            recency_score = max(0, 0.2 - (days_ago * 0.01))
        except:
            pass
    
    # 3. 完全前缀匹配额外加0.2分
    prefix_score = 0.2 if memory.content.lower().startswith(query.lower()) else 0.0
    
    return base_score + count_score + recency_score + prefix_score

# 修改原有的搜索排序逻辑，对cli_command类型的记忆使用特殊权重
```
