# 阶段4：集成测试与验收
## 测试目标
验证所有CLI功能串联运行正常，符合产品需求

---

## 完整流程测试用例
```powershell
# 1. 确保后端服务已启动
uvicorn backend.main:app --reload --port 8000

# 2. 开启监控模式，扫描历史命令
mem watch
# 预期输出：✅ 已扫描历史命令，自动记录了X条高频命令

# 3. 手动执行几次复杂命令
docker ps
docker images
docker ps -a --filter status=exited

# 4. 搜索刚才执行的命令
mem search "docker exited"
# 预期输出：能找到"docker ps -a --filter status=exited"命令

# 5. 测试复制功能
mem search "docker exited" --copy
# 预期输出：✅ 已复制到剪贴板：docker ps -a --filter status=exited

# 6. 保存工作流
mem workflow save "docker清理" "docker system prune -f" "docker volume prune -f"
# 预期输出：✅ 工作流「docker清理」已保存，包含2个步骤

# 7. 执行工作流
mem workflow run "docker清理"
# 预期输出：按步骤提示执行清理命令

# 8. 查看所有记忆
mem list
# 预期输出：包含刚才自动记录的命令和保存的工作流
```
