### 当前系统能力

经过本周期开发，项目已经形成两个方向的联动能力：

1. 方向 A 负责沉淀“具体怎么做”：通过 CLI 记录高频命令、项目目录偏好、工作流步骤和执行反馈。
2. 方向 B 负责沉淀“为什么这么做”：从飞书群聊中提取团队决策、原因、废弃方案和最新规范。
3. 两者共享统一长期记忆底座：CLI 命令、工作流和飞书决策都进入 `memories` 表，并通过 metadata 建立可检索、可重排、可覆盖的记忆结构。
4. 飞书决策可以反向约束 CLI 推荐：当团队在飞书中确认某个规范后，本地命令推荐会自动倾向新规范，减少旧经验继续污染操作建议。

### 下阶段展望

目前，方向 B 已完成核心闭环和接入文档，下一阶段可以围绕“真实交互体验”和“评测说服力”继续增强：

1. 飞书交互卡片升级：将当前文本回复升级为飞书交互卡片，展示决策结论、原因、影响项目、CLI 命令复制按钮和工作流步骤。
2. LLM 决策抽取增强：用大模型替代当前规则抽取，支持从多轮讨论中识别“决策-理由-反对意见-结论”完整结构。
3. 多轮会话聚合：按 `chat_id + topic + 时间窗口` 聚合群聊上下文，解决真实讨论中决策分散在多条消息里的问题。
4. 权限与可信度控制：区分普通成员建议和负责人确认，避免任意一句话直接覆盖团队长期记忆。
5. 方向 B 评测集建设：补充抗干扰群聊、矛盾决策更新、CLI 推荐重排、群内查询提效等 evaluation 测试，为答辩提供量化证据。
